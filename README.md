# Global COVID-19 Interactive Dashboard

A data visualization mini project built using **Python** and **Plotly** to analyze and visualize global COVID-19 statistics through interactive dashboards and charts.

---

## 📌 Project Overview

This project provides an interactive dashboard for analyzing worldwide COVID-19 data. It helps users understand country-wise trends such as:

* Total COVID-19 cases
* Death counts
* Recovery statistics
* Active cases
* Testing analysis
* Global spread visualization

The dashboard is developed using **Plotly**, which provides interactive graphs, maps, and dashboards.

---

## 🚀 Features

* Interactive Plotly charts
* Choropleth world map
* Country-wise analysis
* Death and recovery comparison
* Testing statistics visualization
* Combined dashboard view
* HTML dashboard export

---

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Plotly
* Jupyter Notebook

## 📂 Dataset

The dataset contains global COVID-19 statistics including:

* Country names
* Total cases
* Total deaths
* Active cases
* Recoveries
* Total tests
* Population data

Dataset format: `CSV`

## 📊 Visualizations Included

### 1. Bar Chart

Top countries by total COVID-19 cases.

### 2. Pie Chart

Country-wise death distribution.

### 3. Scatter Plot

Relationship between total cases and total deaths.

### 4. Choropleth Map

Global COVID-19 spread visualization.

### 5. Histogram

Distribution of total cases.

### 6. Interactive Dashboard

Combined dashboard with multiple charts.

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Anil-Codes18/Mini-Project.git
```

Move into the project folder:

```bash
cd Mini-Project
```

Install required libraries:

```bash
pip install pandas numpy plotly
```

---

## ▶️ Run the Project

Run the Python file:

```bash
python covid_dashboard.py
```

or open the notebook in Jupyter Notebook.
